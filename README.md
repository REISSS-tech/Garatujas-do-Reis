# GARATUJA ( ͡ಠ ͜ʖ ͡ಠ)

# Anotações – Programação (1º trimestre)

---

# Webdesign (revisão)

**Webdesign** = criação visual de sites

## Importante

* Layout (organização)
* Cores + fontes
* Responsivo (celular + PC)
* Usabilidade (fácil de usar)

---

# HTML *(eu do futuro)*

**HTML** = estrutura do site

## Usa

* `h1` → título
* `p` → texto
* `img` → imagem
* `a` → link

## Obs

* Não é linguagem de programação

---

# CSS *(eu do futuro)*

**CSS** = estilo do site

## Faz

* Cores
* Tamanhos
* Fontes
* Layout (`flex`, `grid`)

## Resumo

* HTML = base
* CSS = beleza

---

# JS *(eu do futuro)*

**JS** = comportamento do site

## Faz

* Clique em botão
* Animação
* Validação

## Resumo

* JS = interatividade

---

# Projeto

## Simples

* Organizado
* Básico funcionando

## Versão pessoal

* Mais bonito
* Estilo próprio
* Mais informações
* Criatividade

## Diferença

* Professor = básico certo
* Pessoal = completo + estilizado

---

# Java vs JS vs TS

## Java

* Linguagem forte
* Backend / apps
* Compilada

## JS

* Web
* Roda no navegador

## TS

* JS melhorado
* Tem tipos (mais seguro)

## Resumo

* Java ≠ JavaScript
* TS = JS com tipos

---

# POO (Programação Orientada a Objetos)

## O que é

Programar usando objetos

## Vantagens

* Organização
* Reutilização
* Fácil manutenção

---

# Classe

**Classe** = molde (modelo)

---

# Objeto

**Objeto** = instância da classe

### Exemplo

`Classe Carro → meuCarro`

---

# Atributo

Dados do objeto

### Exemplo

* Cor
* Nome
* Idade

---

# Método

Ação do objeto

### Exemplo

* `andar()`
* `falar()`

---

# This

`this` = objeto atual

## Importante

* Não usar nomes genéricos tipo `a`, `b`, `c`
* Sempre usar `this`

---

# Construtor

Roda quando cria o objeto

## Serve para

* Iniciar valores

## Resumo

* O objeto já nasce pronto

---

# Herança

Uma classe herda da outra

### Exemplo

`Animal → Cachorro`

## Vantagem

* Reaproveita código

---

# Encapsulamento

Proteger dados

## Usa

* `public` → tudo acessa
* `private` → só a classe
* `protected` → classe + filhas

## Resumo

* Não deixar bagunçar os dados

---

# Getters e Setters

## Getter

* Pega valor

## Setter

* Altera valor com regra

## Vantagem

* Controle total

---

# Get / Set *(forma moderna)*

Parece atributo normal

### Exemplo

```js
obj.nome
```

Mas por trás existe validação

---

# Polimorfismo

Mesmo método, comportamentos diferentes

### Exemplo

`calcularArea()` muda dependendo da forma

## Resumo

* Mesmo nome → resultado diferente

---

# Static

Pertence à classe

## Importante

* Não precisa criar objeto

## Uso

```js
Classe.metodo()
```

## Resumo

* Não usa `this`

---

# Revisão Final (decorar)

* Classe → molde
* Objeto → instância
* Atributo → dado
* Método → ação
* `this` → objeto atual
* Construtor → inicia valores
* Herança → herda
* Encapsulamento → protege
* Getter / Setter → controla
* Polimorfismo → muda comportamento
* `static` → pertence à classe
